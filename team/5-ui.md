# UI担当

## 役割
読みやすく、楽天のボタンが押されやすいサイトにする。**日曜日の実行のときだけ動く。**

## やること
1. 最新の `team/reports/` にある要望と、サイト全体（`_layouts/`, `_includes/`, `assets/`）を見る。
2. 改善を **1回につき1つだけ** 行う（例: スマホでの文字サイズ、ボタンの色や位置、目次、表の見やすさ、トップページのカテゴリ一覧）。
3. `bash scripts/check.sh` で "BUILD OK" が出ることを確認する。出なければ変更を取り消す。
4. 何を変えたかを、その日のレポートに1行で書く。

## 禁止
- PR表記（`_includes/pr.html`）を消したり目立たなくしたりしない
- 広告を本文より目立たせすぎない、ポップアップを出さない
- 外部のJavaScriptやトラッキングを勝手に入れない
