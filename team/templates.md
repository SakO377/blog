# 記事の型（テンプレート）

分析（team/research/）から作った記事の型。ネタ探し担当が型を1つ選び、記事作成担当はその見出し構成に沿って書く。同じ型を2日続けて使わない。見出しの文言は記事ごとに言い換えてよい。

## A. 家電・ガジェットのおすすめ記事（実機なしで勝つ型）
おすすめ記事（例：一人暮らし向けロボット掃除機）

```
# 【2026年版】一人暮らし向けロボット掃除機の選び方とおすすめ○選｜スペックで比較

（冒頭の上）PR表記：この記事には広告（楽天アフィリエイト）が含まれます
（冒頭の上）公開日 / 最終更新日 / 価格確認日

## 結論：迷ったらこれ（30秒でわかる）
- 迷ったら：商品A（理由1行）［商品カード］
- 安さ重視なら：商品B（理由1行）［商品カード］
- 水拭きもしたいなら：商品C（理由1行）［商品カード］


## 選び方：まずこの3つだけ見ればOK
### 1. 部屋の広さ・段差（数字の目安つき）
### 2. ゴミ捨て・お手入れの手間
### 3. 予算（いくらで何ができるか）
> 用語メモ：「LiDAR」「Pa」とは？

## 比較表（スペックは公式の数字）
| 商品 | 価格 | 吸引力 | 高さ | 段差 | 自動ゴミ収集 | 水拭き | 楽天レビュー |
（表の下に出典リンク）

## タイプ別おすすめ
### ワンルームで置き場所が少ない人には：商品A
- ひとことで言うと / 良い点 / 気になる点 / 楽天レビューのまとめ / こんな人には向かない
- ［商品カード：楽天で価格を見る］
### とにかく安く始めたい人には：商品B
### ペットや髪の毛が気になる人には：商品C

## 前のモデル・ライバル製品との違い

## 買う前のチェックリスト（よくある失敗）

## よくある質問（Q&A）

## まとめ：もう一度、結論
（まとめ比較表＋商品カード）

## この記事について
- 作り方（AIで下書き→人が公式情報で確認）/ 編集ポリシーへのリンク / 誤りの報告先

## B. 準備リスト型 / C. 買ってよかった○選型 / D. 100均の代わり型 / E. セール便乗型（暮らし・キャンプ・ベビー）
#### テンプレ1：○○の準備リスト型（キャンプ・出産準備・一人暮らしの初期そろえ）
```
タイトル：【○○ 準備リスト】最初に買うもの・あとでいいもの・いらないもの（○年版）
（PR表記）
はじめに：この記事でわかること（3行）
## 結論：最低限これだけあればOK（○点の表：品名／個数／目安の値段）
## 準備はいつから？（時期別のスケジュール）
## 最初に買うもの
### 品名1（選ぶポイント3つ → 楽天ボタン）
### 品名2 …
## あとで買えばいいもの（理由つき）
## 買わなくてよかったもの・レンタルでいいもの（理由と代わりの方法）
## 費用の目安（最低限プラン／ひと通りプラン）
## まとめて買うなら：セットの表＋楽天ボタン（買い回りの説明）
## 印刷・保存用チェックリスト（画像1枚）
## よくある質問（3〜5個）
## まとめ（3行）＋関連記事
```

#### テンプレ2：買ってよかった○選型（一人暮らし・収納・キッチン）
```
タイトル：一人暮らしで買ってよかった○○ ○選｜場所別に紹介
（PR表記）
はじめに：こんな人向け（3つ）
## 一覧表（場所／品名／値段の目安／ひとことでいうと）
## キッチン編
### 品名（困っていたこと → どうなったか → 気になる点 → 楽天ボタン）
## お風呂・洗面所編
## 収納編
## 掃除・洗濯編
## 正直いらなかった物
## 1,000円台で買える物まとめ（買い回り用）
## まとめ＋関連記事
```

#### テンプレ3：100均の代わり型
```
タイトル：○○は100均のどこに売ってる？ネットで買う方法と楽天の代わり
（PR表記）
## 結論（どの店にある・ネットで買えるか）
## ダイソー・セリア・キャンドゥのちがい（表）
## ネットで買う方法（公式通販の有無・送料が無料になる金額）
## 楽天で買える「ちょっといい」代わり3選（100均との違いを表で）
## 100均で十分な人・楽天のほうがいい人
## まとめ
```
注：店の通販の条件はよく変わる（ヨムーノもHugKumも「変わる場合がある」と書いている）。記事に確認日を入れる。

## F. お得情報の定番記事・単発キャンペーン記事
**定番記事（お買い物マラソン／スーパーSALE）**
```
（自動）本記事はプロモーションを含みます
（自動）期間限定 ○年○月○日まで ／ 終了しました
最終更新：○年○月○日 ○時（このページは毎回更新します）

<point-box> この記事でわかること（3行）

## 結論：今回のお買い物マラソンは○月○日（○）○時まで、最大○倍
| 項目 | 内容 |
| 期間 | ○月○日（○）20:00〜○月○日（○）1:59 |
| 最大ポイント | ○倍（買い回り10店で+9倍） |
| 条件 | エントリー必須／1店1,000円（税込）以上 |
| もらえる上限 | ○ポイント |
| 確認日・出典 | ○年○月○日時点・楽天市場の公式ページ（リンク） |
[楽天ボタン] エントリーページを開く

## まずやること3つ（エントリー・5と0のつく日・楽天カード）
## よくある失敗（クーポン後に1,000円を切る、送料別、11店目以降は増えない等）
## 【ジャンル別】今回おすすめの商品
### 家電（選び方記事へのリンク付き）
### キャンプ・アウトドア
### 一人暮らしの日用品
  （商品名／通常価格→セール価格（○%OFF）／○日○時時点／[楽天ボタン]）
## 買い回りの数合わせにおすすめ：1,000円台の日用品
## 次のセールはいつ？（予想と書く・カレンダー記事へ）
## まとめ（期限をもう一度＋エントリーボタン）
```

**単発キャンペーン記事（格安SIMの乗り換えキャンペーンなど）**
```
## 結論：○月○日までに申し込むと、最大○円おトク
| いくら得 | いつまで | 条件 | 確認日・出典 |
## キャンペーンの中身（公式の言葉で）
## もらうための手順（1→2→3）
## 対象外になるケース・注意点
## 向いている人・向いていない人（選び方記事へのリンク）
## まとめ（期限＋ボタン）
```

### 更新のしかた（毎朝の流れ）
1. 期限が過ぎた `expires` の記事を探す（今のルールどおり）。
2. 次の回が始まっていれば、**同じファイルを上書き**（URLはそのまま）。タイトルの【年月】、表の期間・倍率・上限、商品の価格、`expires`、`last_modified_at` を全部変える。

## G. 格安SIM・通信（体験レビュー / キャンペーンまとめ / 疑問に答える / 乗り換え手順）
#### 型1: 体験レビュー（「IIJmio 評判 / 使ってみた」）
```
タイトル: IIJmioを〇年使った正直レビュー｜月〇円・昼の速度・不満点まで【2026年〇月】
(PR表記 / 公開日・更新日 / 「料金は〇月〇日時点・公式で確認」)
## 【結論】IIJmioはこんな人におすすめ（向いている人 / 向いていない人を3つずつ）
   → 申込ボタン①「IIJmio公式サイトで料金を見る」
## 私の使い方と毎月の支払い（実際の請求のスクショ、プラン、何か月使ったか）
## 実際の速度（朝・昼・夜の測定結果の表、測定アプリ・場所・日付）
## よかったところ（3〜5個、体験つき）
## 不満なところ・デメリット（3〜5個、正直に）
## ほかの格安SIMとの料金比較表（同じ容量で、楽天モバイル / povo / ahamoなど）
## 今やっているキャンペーン（データファイルから出す、期限つき）
   → 申込ボタン②
## 申し込みの手順（3〜6STEP、スクショ）
## よくある質問（5〜8問）
## まとめ（結論をもう一度）→ 申込ボタン③
```

#### 型2: キャンペーンまとめ（毎月更新）
```
タイトル: 【2026年〇月】IIJmioキャンペーンまとめ｜今いちばんお得なのは〇〇
## 【結論】今月いちばんお得な使い方（1〜2行）→ ボタン
## キャンペーン一覧表（名前 / 特典 / 条件 / 期限 / 対象（新規・乗り換え・今使っている人））
## 乗り換えの人向け / 新規の人向け / 今使っている人向け（h3で分ける）
## 注意点（対象外になる条件、一緒に使えない組み合わせ、すぐ解約するリスク）
## 終わったキャンペーン（過去の履歴として残す → 「次はいつ？」と検索する人も来る）
## よくある質問
## まとめ → ボタン
```

#### 型3: 疑問に答える記事（AIで量産する用、短め）
```
タイトル: 〇〇は△△？→答え（〜です）【2026年〇月時点】
## 結論（2〜3行で答える、公式の出典リンク）
## くわしい説明（表を1つ）
## 私の場合（運営者の体験メモ。AIの文ではなく、人が書いた一言を入れる）
## 注意点
## 関連記事（型1・型2へのリンク）→ ボタンは1つだけ
```

## STEP1〜6（それぞれスクショ）
## よくある失敗と、その対処
## よくある質問
## まとめ → ボタン
